## 定义和适用范围

所有设备、测量信号和材料目标均为仿真，不连接真实硬件。

- 电解液：从仿真 EIS 提取体电阻近似值，`κ = 1000 K_cell / R_b`，单位 mS/cm；不是完整等效电路拟合。
- TIM：`α = 0.1388 d²/t_half`、`k = αρc_p`；目标分数还含黏度惩罚。
- Cavity：从仿真 S21 幅度拟合频率和 Q，再反演 Dk/Df；目标分数还含 Dk 与黏度惩罚。
- 设备失败不作为配方低分反馈；配方不可行则反馈配置中的惩罚值。
- 模拟计时包含压缩后的 Python 调度开销，不能作为真实设备吞吐率。
- 反演一致性测试不等于真实仪器标定，单次运行也不能证明优化器普遍优于随机搜索。

## 重跑方法

先按 [README](../README.md) 创建环境并安装开发依赖，再在项目根目录执行：

~~~bash
.venv/bin/python -m pip check
.venv/bin/python -m pytest -q
~~~

整体验收：

~~~bash
.venv/bin/python scripts/validate_project.py
.venv/bin/python scripts/validate_project.py --full
~~~

默认检查六个命令行用例和调度对照；`--full` 额外检查电解液 48 样品运行。
每次验收都在 `data/validation-*/` 中生成独立的日志和 JSON 结果，不覆盖已有记录。
`data/` 是本地生成目录，不纳入版本控制。

测试不需要硬件或外部模型 API。实验参数、测试代码和验收脚本随仓库提供。
